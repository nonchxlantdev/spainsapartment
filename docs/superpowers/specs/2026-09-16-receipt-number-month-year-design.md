# Receipt numbers: Initials + MM + YYYY + ordinal from start

**Date:** 2026-09-16  
**Status:** Approved (revised)

## Format

`{FirstInitial}{LastInitial}{MM}{YYYY}{####}`

- `MMYYYY` = the payment’s month/year  
- `####` = that tenant’s receipt count **from onboard / new lease start forward** (1st payment = 0001, 2nd = 0002, …). Not reset each month; not tied to calendar month names.

Example (Wilbense, lease from July 2026):  
- Jul → `WN0720260001`  
- Aug → `WN0820260002`  
- Sep → `WN0920260003`
